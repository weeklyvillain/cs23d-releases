# cs23d

Watch Counter-Strike 2 demos in 3D, with the game's own look, and export them as videos.

## Install

Download `cs23d-setup-<version>.exe` from the newest [release](https://github.com/weeklyvillain/cs23d-releases/releases/latest) and run it.

- **Windows 10 or 11**, and **CS2 installed through Steam**: maps, player models, weapons and sounds are read from your own game files, so nothing of Valve's is shipped here.
- The first time you open a demo on a map, cs23d builds that map from your CS2 install (a few seconds).
- To export videos you need ffmpeg; the installer can install it for you.

## Updates

cs23d checks this page for newer versions. When one is out, a button appears in its title bar: click it to download the update, then restart to install it.
